# Discord Image Status

好きな画像と文章を、Discordプロフィールの「アクティビティ」欄に表示するWindows向けプログラムです。
SoundCloudを再生する必要はありません。ブラウザー拡張機能も不要です。
画像URL、またはDiscordの管理画面にアップロードした画像のアセット名を使います。

## はじめ方

1. ZIPを「すべて展開」してください。
2. Discordデスクトップ版を起動します。
3. `START.cmd` をダブルクリックします。日本語の設定画面が開きます。
   - 開かない場合は http://127.0.0.1:32146 を開いてください。
   - Node.js 20以上が必要です。未導入の場合は https://nodejs.org/ からLTS版を導入します。
4. https://discord.com/developers/applications を開き、New Applicationからアプリを作成します。
5. General InformationにあるApplication IDを、設定画面に入力します。
6. 表示したい画像の直接URL、タイトル、説明を入力します。
7. 「保存して表示」を押します。
8. Discordのアクティビティ共有を有効にし、プロフィールのアクティビティ欄を確認してください。

Botの作成、サーバーへの招待、Discordユーザートークン、Client Secretは不要です。

## PCに保存した画像を表示する

Discordから取得できる場所に画像をアップロードする必要があります。

1. プログラムの設定画面にApplication IDを入力します。
2. 「画像のアップロード画面を開く」を押します。
3. Developer PortalのRich Presence → Art Assetsで、使いたい画像をアップロードします。
4. 画像に付けたアセット名（例：my_image）を「画像URL または アセット名」に入力します。
5. 「保存して表示」を押します。

ローカルファイルのパスやクリップボード内の画像を、そのままDiscordへ送る機能はありません。画像のアップロードは上記の管理画面で行います。
アセット名で指定した画像は設定画面のプレビューには出ません。Discord上で確認してください。

## 公開画像URLを使う

https:// で始まり、ログインせず画像そのものを取得できるURLを指定します。
画像を紹介するWebページのURL、PCのファイルパス、ログイン必須の画像は利用できません。
期限のあるURLは期限切れ後に表示できなくなります。画像の反映にはDiscord側のキャッシュにより時間がかかる場合があります。
プログラムは画像を自動で外部サービスへアップロードしません。

## 日常の操作

- 画像や文章を変える：入力を変更して「保存して表示」
- 非表示にする：「表示を停止」
- 次回起動：START.cmdをダブルクリック。保存した設定で表示を再開します。停止設定も保存されます。
- 終了：プログラムのウィンドウでCtrl+C。終了時にアクティビティを解除します。
- Discordを再起動：連携プログラムが自動で再接続します。
- Application IDを変更：プログラムを終了し、同じフォルダーのconfig.jsonを削除して再起動します。他の表示設定も初期化されます。

画像はアクティビティカードに表示されます。プロフィールのアイコンやバナー、Spotifyの専用再生カードを書き換える機能ではありません。
アクティビティの種類は「聴いている」「プレイ中」「視聴中」から選べます。
複数のRich Presenceプログラムを動かすと表示が切り替わることがあるため、以前のSoundCloud版は終了してから使ってください。

## 配布・GitHubへの公開

ソースコードとこの説明書を同梱しています。追加のnpmパッケージは使っていません。
ZIPを展開したファイルをリポジトリに追加できます。config.jsonは個人の表示設定を含むため公開しないでください。.gitignoreで除外しています。
GitHubで公開する場合は、利用条件に合うライセンスを別途選んでください。

## 確認状況

自動テスト5件に合格しています。画像URLとアセット名の受け付け、表示内容、非表示、設定保存、実際のWindows名前付きパイプを使った模擬Discordとの通信を確認しました。
実際のDiscordプロフィールでの画像表示は、本人のApplication IDと画像を設定した後に確認してください。
設定画面の「Discordが更新を受け付けました」は送信への応答を示します。Discord側の画像取得が成功したかはプロフィールで確認してください。

テストの実行：このフォルダーで `npm test`
